Ερώτηση 1:¶

Ο πρώτος δεξιός singular vector v του πίνακα A προκύπτει ως η διεύθυνση πάνω στην οποία οι γραμμές του πίνακα έχουν τη μεγαλύτερη συνολική προβολή. Η ποσότητα που μεγιστοποιεί το SVD είναι η ||Av||^2, η οποία γράφεται ως άθροισμα τετραγώνων των προβολών των διανυσμάτων γραμμών (θεωρούμε ότι το διάνυσμα v είναι μοναδιαίο, δηλαδή ∥v∥=1, ώστε οι προβολές να ορίζονται σωστά και το πρόβλημα μεγιστοποίησης να είναι καλά ορισμένο):

||Av||^2 = Σ(i=1 έως i=n)((ai[Transpose]v)^2)

Από τη γεωμετρία της προβολής, για κάθε διάνυσμα ai ισχύει:

||ai = (ai[Transpose]v)||^2 = ||ai||^2 - ((ai[Transpose]v)^2)

Επομένως, το άθροισμα των αποστάσεων των διανυσμάτων από τις προβολές τους πάνω στη διεύθυνση v είναι:

Σ(i=1 έως i=n)(||ai = (ai[Transpose]v)||^2) = Σ(i=1 έως i=n)(||ai||^2) - Σ(i=1 έως i=n)((ai[Transpose]v)^2)

Επειδή το πρώτο άθροισμα δεν εξαρτάται από το v, το διάνυσμα που ελαχιστοποιεί τις αποστάσεις από τις προβολές είναι ακριβώς αυτό που μεγιστοποιεί το Σ((ai[Transpose]v)^2).

Παρατηρούμε ότι:

Σ(i=i έως i=n)((ai[Transpose]v)^2) = ||Av||^2 = v[Transpose]A[Transpose]Av

Για ||v||=1 η ποσότητα αυτή μεγιστοποιείται όταν το v είναι το ιδιοδιάνυσμα του A[Transpose]A που αντιστοιχεί στη μέγιστη ιδιοτιμή, δηλαδή ο πρώτος δεξιός singular vector του πίνακα Α.

Το SVD επιλέγει ως πρώτο δεξιό singular vector τη διεύθυνση που μεγιστοποιεί αυτήν την ποσότητα, άρα και τη διεύθυνση που ελαχιστοποιεί τη συνολική απόσταση των γραμμών από τις προβολές τους.

Έτσι, αποδεικνύεται ότι ο πρώτος δεξιός singular vector v είναι το διάνυσμα που ελαχιστοποιεί το άθροισμα των τετραγώνων των αποστάσεων των a1,...,an από τις προβολές τους πάνω στη διεύθυνση v.

Ερώτηση 2:¶

A. MLE για μία power-law κατανομή# Για την κατανομή P(X=x)=(a-1)*x^(-a), η log-likelihood των δεδομένων x1,...,xn είναι (θεωρούμε ότι οι παρατηρήσεις ικανοποιούν xi≥1, ώστε η κατανομή power-law να είναι κανονικοποιήσιμη):

l(a) = nln(a-1) - aΣ(i=1 έως i=n)(ln(xi))

Η μεγιστοποίηση ως προς το a οδηγεί στην κλασική MLE εξίσωση και η log-likelyhood προκύπτει από:

l(a) = n * ln(a-1) - a * Σ(i=1 έως i=n)(ln(xi))

και η μεγιστοποίησή της ως προς a δίνει την εξίσωση που ακολουθεί:

a^ = 1 + ((1/n)Σ(i=1 έως i=n)(ln(xi)))^(-1)

Έτσι, ο εκθέτης που ταιριάζει καλύτερα στα δεδομένα εξαρτάται από τον μέσο όρο των λογαρίθμων των παρατηρήσεων: όσο πιο «βαριές» είναι οι ουρές της κατανομής, τόσο μικρότερη είναι η εκτίμηση του a^.

Ο παραπάνω τύπος προκύπτει θέτοντας dl(a)/da = 0 και λύνοντας ως προς α.

B. Μείγμα δύο power-law κατανομών & EM αλγόριθμος Υποθέτουμε ότι τα δεδομένα προέρχονται από μείγμα δύο power-law κατανομών με παραμέτρους a1, a2 και πιθανότητες μίξης π1, π2. Η πιθανότητα για κάθε παρατήρηση xi στο mixture μοντέλο δίνεται από:

P(xi) = π1(a1-1)xi^(-a1) + π2(a2-1)xi^(-a2) + . . .

με π1+π2=1 και xi>=1.

Στο Ε-βήμα του EM αλγορίθμου υπολογίζονται οι responsibilities:

γi1 = (π1(a1-1)xi^(-α1)) / ((π1(a1-1)xi^(-a1)) + (π2(a2-1)xi^(-a2))) και γi2 = 1 - γi1

Στο Μ-βήμα ενημερώνονται οι παράμετροι. Οι πιθανότητες μίξης ενημερώνονται ως:

π1 = 1/n * Σ(i=1 έως i=n)(γi1) και π2 = 1 - π1

Οι εκθέτες των δύο power-law κατανομών ενημερώνονται με weighted MLE:

a1 = 1 + ((Σ(i=1 έως i=n)(γi1))/(Σ(i=1 έως i=n)(ln(xi)))) και a2 = 1 + ((Σ(i=1 έως i=n)(γi2))/(Σ(i=1 έως i=n)(ln(xi))))

Οι επαναλήψεις Ε- και Μ-βημάτων συνεχίζονται έως ότου οι παράμετροι (a1, a2, π1, π2) συγκλίνουν. Οι παραπάνω εξισώσεις προκύπτουν απευθείας από τη διαδικασία που χρησιμοποιήθηκε στην τάξη για Gaussian mixtures, προσαρμοσμένη στην power-law πιθανοφάνεια.

Ερώτηση 3:¶

Εδώ εξετάζουμε στην πράξη διαφορετικούς αλγορίθμους συστάσεων, χρησιμοποιώντας πραγματικά δεδομένα από βαθμολογίες χρηστών σε ταινίες. Το αρχείο data-train.csv περιέχει το μεγαλύτερο μέρος των δεδομένων και χρησιμοποιείται για την εκπαίδευση των μοντέλων, ενώ το data-test.csv περιλαμβάνει τις υπόλοιπες βαθμολογίες και εξυπηρετεί αποκλειστικά την αξιολόγηση. Η εκπαίδευση των αλγορίθμων γίνεται μόνο στο σύνολο data-train, ενώ η αξιολόγηση πραγματοποιείται αποκλειστικά στο data-test. Οι πίνακες χρηστών και ταινιών ξεκινούν από το μηδέν, γεγονός που διευκολύνει την αναπαράστασή τους με numpy ή sparse δομές, αλλά και την εφαρμογή πράξεων όπως μέσοι όροι, γινόμενα πινάκων ή μετρήσεις ομοιότητας.

Στο πλαίσιο της άσκησης υλοποιούνται τέσσερις αλγόριθμοι: δύο απλές baseline μέθοδοι (μέσος όρος χρήστη και μέσος όρος ταινίας), ένα μοντέλο βασισμένο στη διάσπαση SVD και ένας user-based collaborative filtering αλγόριθμος. Στις baseline μεθόδους, η προβλεπόμενη βαθμολογία προκύπτει αντίστοιχα από τον μέσο όρο των βαθμολογιών του χρήστη ή της ταινίας. Το μοντέλο SVD προβλέπει βαθμολογίες μέσω παραγοντοποίησης του πίνακα χρηστών–ταινιών σε λανθάνουσες διαστάσεις, ενώ ο αλγόριθμος collaborative filtering βασίζεται στις ομοιότητες χρηστών και υπολογίζει προβλέψεις αξιοποιώντας χρήστες με παρόμοια συμπεριφορά. Οι προβλέψεις παράγονται μόνο για τα ζεύγη (χρήστης, ταινία) που εμφανίζονται στο σύνολο data-test.

Για την αξιολόγηση των μοντέλων χρησιμοποιείται η μετρική RMSE, η οποία μετρά την απόκλιση ανάμεσα στις προβλέψεις και στις πραγματικές βαθμολογίες και υπολογίζεται αποκλειστικά πάνω στις βαθμολογίες του data-test. Μικρότερη τιμή RMSE υποδηλώνει καλύτερη απόδοση και πιο αξιόπιστες προτάσεις. Η διαδικασία αυτή επιτρέπει τη σύγκριση των διαφορετικών αλγορίθμων συστάσεων βάσει της απόδοσής τους, αναδεικνύοντας πότε οι πιο σύνθετες τεχνικές υπερτερούν και πότε οι απλές baseline μέθοδοι είναι ήδη αρκετά ανταγωνιστικές.

# Import numpy for numerical operations
import numpy as np
# Import sparse matrix structure
from scipy.sparse import csr_matrix
# Import truncated SVD
from scipy.sparse.linalg import svds
# Import RMSE metric
from sklearn.metrics import mean_squared_error
# Import square root for RMSE
from math import sqrt
# Import time for performance measurement
import time

# Compute number of users
n_users  = train_1["uid"].max() + 1
# Compute number of movies
n_movies = train_1["mid"].max() + 1

# Extract user indices
rows = train_1["uid"]
# Extract item indices
cols = train_1["mid"]
# Extract rating values
vals = train_1["rating"]

# Build sparse user–item rating matrix
R = csr_matrix((vals, (rows, cols)), shape=(n_users, n_movies))

# Compute truncated SVD with 20 latent factors
U, S, VT = svds(R, k=20)

# Get indices to sort singular values descending
idx = np.argsort(-S)
# Reorder singular values
S = S[idx]
# Reorder user latent matrix
U = U[:, idx]
# Reorder item latent matrix
VT = VT[idx, :]

# Extract user ids from test set
test_users   = test_1["uid"].values
# Extract item ids from test set
test_items   = test_1["mid"].values
# Extract true ratings from test set
test_ratings = test_1["rating"].values

# Define fast vectorized SVD prediction function
def predict_svd_fast(k):
    # Select top-k user latent factors
    Uk = U[:, :k]
    # Build diagonal matrix of top-k singular values
    Sk = np.diag(S[:k])
    # Select top-k item latent factors
    Vk = VT[:k, :]

    # Precompute item-side matrix
    M = Sk @ Vk

    # Compute predictions for all test pairs
    preds = np.sum(Uk[test_users] * M[:, test_items].T, axis=1)

    # Clip predictions to valid rating range
    return np.clip(preds, 0, 5)

# Define range of k values
Ks = range(1, 21)
# Initialize list for RMSE values
rmse_svd_fast = []

# Start timing
start = time.time()

# Loop over k values
for k in Ks:
    # Compute predictions
    preds = predict_svd_fast(k)
    # Compute RMSE
    rmse = sqrt(mean_squared_error(test_ratings, preds))
    # Store RMSE
    rmse_svd_fast.append(rmse)

# End timing
end = time.time()

# Print total execution time
print("FAST SVD TIME:", end - start, "seconds")

# Print RMSE results for each k
for k, r in zip(Ks, rmse_svd_fast):

# Define function to find top-k users similar to user u
def similar_users_4(R, u, m_users, k):
    # Return empty arrays if no users rated the item
    if len(m_users) == 0:
        return np.array([]), np.array([])

    # Extract rating vector of target user
    u_vec = R.getrow(u)
    # Extract rating vectors of other users
    others = R[m_users]

    # Compute dot products between users
    dots = others.dot(u_vec.T).toarray().flatten()

    # Compute norm of target user vector
    u_norm = np.sqrt(u_vec.multiply(u_vec).sum())
    # Compute norms of other user vectors
    o_norm = np.sqrt(others.multiply(others).sum(axis=1)).A.flatten()

    # Compute denominator for cosine similarity
    denom = u_norm * o_norm
    # Avoid division by zero
    denom[denom == 0] = 1e-9

    # Compute cosine similarities
    sims = dots / denom

    # Sort users by similarity descending
    idx = np.argsort(-sims)
    # Select top-k similar users
    top_users = m_users[idx][:k]
    # Select corresponding similarities
    top_sims  = sims[idx][:k]

    # Return top users and their similarities
    return top_users, top_sims

# Define function to compute weighted rating score
def compute_score_4(k_ratings, k_sims):
    # Return zero if no neighbor ratings exist
    if len(k_ratings) == 0:
        return 0
    # Return zero if all similarities are zero
    if np.all(k_sims == 0):
        return 0
    # Compute weighted average of ratings
    return np.dot(k_ratings, k_sims) / np.sum(k_sims)

def predict_ucf_4(u, m, k):
    # Convert user id to integer index
    u = int(u)
    # Convert item id to integer index
    m = int(m)

    # Cache users who rated item m
    if m not in item_users_cache_4:
        item_users_cache_4[m] = item_users_4(R_4, m)
    m_users = item_users_cache_4[m]

    # Fallback to user mean if item has no ratings
    if len(m_users) == 0:
        return user_mean_4(R_4, u)

    # Find top-k similar users
    top_users, top_sims = similar_users_4(R_4, u, m_users, k)

    k_ratings = R_4[top_users, m].toarray().flatten()

# Import sparse matrix structure
from scipy.sparse import csr_matrix
# Import pandas for data loading
import pandas as pd
# Import numpy for numerical operations
import numpy as np
# Import RMSE metric
from sklearn.metrics import mean_squared_error
# Import square root for RMSE
from math import sqrt
# Import time for performance measurement
import time

# Load training dataset
train_4 = pd.read_csv("data_train.csv")
# Load test dataset
test_4  = pd.read_csv("data_test.csv")

# Compute number of users
n_users_4  = train_4["uid"].max() + 1
# Compute number of movies
n_movies_4 = train_4["mid"].max() + 1

# Extract user indices
rows_4 = train_4["uid"]
# Extract item indices
cols_4 = train_4["mid"]
# Extract rating values
vals_4 = train_4["rating"]

# Build sparse user–item rating matrix
R_4 = csr_matrix((vals_4, (rows_4, cols_4)), shape=(n_users_4, n_movies_4))

# Precompute L2 norm of each user vector
user_norms_4 = np.sqrt(R_4.multiply(R_4).sum(axis=1)).A.flatten()

# Convert sparse matrix to dense item–user matrix
R_item_dense_4 = R_4.toarray().T

# Initialize cache for item-to-users mapping
item_users_cache_4 = {}

# Define fast item-to-users lookup with caching
def item_users_fast_4(m):
    # Cache users who rated item m
    if m not in item_users_cache_4:
        item_users_cache_4[m] = R_4[:, m].nonzero()[0]
    # Return cached user indices
    return item_users_cache_4[m]

# Define batch UCF prediction function
def predict_all_ucf_v4(test_users_4, test_items_4, Ks_4):
    # Convert k values to numpy array
    Ks_4  = np.array(Ks_4)
    # Determine maximum k
    maxK_4 = Ks_4.max()
    # Number of test samples
    N_4 = len(test_users_4)

    # Initialize prediction matrix
    preds_4 = np.zeros((N_4, len(Ks_4)))
    # Get unique items in test set
    unique_movies_4 = np.unique(test_items_4)

    # Loop over each item
    for m in unique_movies_4:

        # Get indices of test rows for item m
        rows_idx_4 = np.where(test_items_4 == m)[0]
        # Extract corresponding users
        tu_4 = test_users_4[rows_idx_4]

        # Get users who rated item m
        m_users_4 = item_users_fast_4(m)

        # Handle items with no ratings
        if len(m_users_4) == 0:
            preds_4[rows_idx_4, :] = 0
            continue

        # Compute dot products between users and neighbors
        dots_4 = R_item_dense_4[tu_4][:, m_users_4]

        # Compute user norms
        u_norm_4 = user_norms_4[tu_4][:, None]
        # Compute neighbor norms
        o_norm_4 = user_norms_4[m_users_4][None, :]
        # Compute denominator for cosine similarity
        denom_4 = u_norm_4 * o_norm_4
        # Avoid division by zero
        denom_4[denom_4 == 0] = 1e-9

        # Compute cosine similarities
        sims_4 = dots_4 / denom_4

        # Get number of available neighbors
        L_4 = sims_4.shape[1]
        # Clamp effective k
        K_eff_4 = min(maxK_4, L_4)

        # Partially sort similarities to get top neighbors
        part_4 = np.argpartition(-sims_4, K_eff_4-1, axis=1)[:, :K_eff_4]

        # Build row indices for sorting
        row_idx_4 = np.arange(len(sims_4))[:, None]
        # Sort top neighbors by similarity
        order_4 = part_4[row_idx_4, np.argsort(-sims_4[row_idx_4, part_4], axis=1)]

        # Loop over each test row
        for r, ord_row in enumerate(order_4):

            # Extract neighbor similarities
            neigh_sims_4 = sims_4[r, ord_row]
            # Extract neighbor user indices
            neigh_users_4 = m_users_4[ord_row]

            # Extract neighbor ratings
            ratings_4 = R_item_dense_4[m, neigh_users_4]

            # Compute cumulative weighted ratings
            cum_w_4 = np.cumsum(ratings_4 * neigh_sims_4)
            # Compute cumulative similarity sums
            cum_s_4 = np.cumsum(neigh_sims_4)

            # Number of neighbors
            L2_4 = len(cum_s_4)

            # Loop over k values
            for j, k in enumerate(Ks_4):

                # Handle insufficient neighbors or zero similarity
                if k > L2_4 or cum_s_4[k-1] == 0:
                    preds_4[rows_idx_4[r], j] = 0
                # Compute weighted average prediction
                else:
                    preds_4[rows_idx_4[r], j] = cum_w_4[k-1] / cum_s_4[k-1]

    # Clip predictions to valid rating range
    return np.clip(preds_4, 0, 5)

# BONUS 1 — centered similarities

# Define function to find top-k similar users using centered ratings
def similar_users_centered_B1(Rc, u, m_users, k):
    # Return empty arrays if no users rated the item
    if len(m_users) == 0:
        return np.array([]), np.array([])

    # Extract centered rating vector of target user
    u_vec = Rc[u].toarray()
    # Extract centered rating vectors of other users
    others = Rc[m_users].toarray()

    # Compute dot products between centered vectors
    dots = (others * u_vec).sum(axis=1)
    # Compute norm of target user vector
    u_norm = np.linalg.norm(u_vec)
    # Compute norms of other user vectors
    o_norm = np.linalg.norm(others, axis=1)

    # Compute denominator for cosine similarity
    denom = u_norm * o_norm
    # Avoid division by zero
    denom[denom == 0] = 1e-9

    # Compute cosine similarities
    sims = dots / denom
    # Sort users by similarity descending
    idx = np.argsort(-sims)

    # Return top-k users and their similarities
    return m_users[idx][:k], sims[idx][:k]
